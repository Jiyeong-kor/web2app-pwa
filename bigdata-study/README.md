# 빅데이터분석기사 필기 공부 PWA

아이폰 13 mini를 포함한 모바일 화면에서 한 문항씩 풀도록 만든 개인 학습용 PWA입니다.

## 재사용한 검증 자산

- Notion의 제12회 기출복원 80문항과 정답·핵심 해설
- 기존 ADsP·빅데이터 학습 HTML에서 효과가 확인된 한 문항 진행 방식
- `모르겠음`, 첫 답안, 정오, 자신감, 해설 확인, 오답 이유, 풀이 시간 저장 구조
- 브라우저 저장소를 사용한 중단·이어풀기와 오프라인 동작
- 기존 `web2app-pwa` 저장소와 GitHub Pages 배포 기반

## 주요 기능

- 80문항 전체, 과목별 20문항, 미풀이 문항, 오답·모르겠음 재시험
- 해설 확인 후 다음 문항 이동
- 최근 5문항 중 3문항 이상 오답·모르겠음 또는 같은 개념 2회 이상 취약 시 개념 복습 권고
- 정의 → 판단 기준 → 혼동 개념 → 예시 → 미니 확인 순서의 개념 학습
- 자동 저장과 이어풀기
- JSON 백업·복원
- 서비스 워커 기반 오프라인 실행
- iPhone Safe Area와 44px 이상 터치 영역 대응

## 원본 자료 예외 처리

- 21번과 63번은 Notion 원문에 도표가 별도였으므로 학습용 SVG 상자그림을 다시 그렸습니다.
- 33번은 원본 선택지가 촬영되지 않아 단답형으로 제공합니다.
- 31번은 원문 질문과 정답표가 충돌하여 독립표본 t검정의 정의에 맞게 ①로 교정했습니다.
- 74번은 정답 번호는 유지하고 다른 문항과 섞인 해설 문장만 교정했습니다.

## 로컬 실행

정적 파일만 사용하므로 `bigdata-study` 디렉터리에서 간단한 HTTP 서버를 실행하면 됩니다.

```bash
python3 -m http.server 8080
```
